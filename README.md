# Prueba Técnica Fullstack .NET + Angular


## Objetivo


Identificar y corregir problemas en una aplicación existente.


## Consideraciones


No es necesario corregir todos los problemas.


Se evaluará:


- Capacidad de análisis e identificacion de la mayor cantidad de posibles problemas.

- Diseño de APIs REST

- Angular

- Buenas prácticas

- Organización del código

- Uso de Git

## Backend


Revise:


- Diseño REST

- Verbos HTTP

- DTOs

- Validaciones

- Manejo de errores

- Servicios

- Repositorios


## Frontend


Revise:


- Routing

- Navegación

- Servicios HTTP

- Tipado

- Templates

- Manejo de errores

## Entrega


1. Crear una rama propia.

2. Realizar commits descriptivos.

3. Abrir un Pull Request.

4. Documentar:

   - Problemas/Hallazgos detectados.

   - Soluciones implementadas.

   - Mejoras pendientes.
